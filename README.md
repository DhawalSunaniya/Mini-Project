# 🌍 EarthGuardians — Environmental Preservation Website

**EarthGuardians** is a mini-project website focused on **environmental preservation, sustainability, climate action, deforestation prevention, and wildlife protection**.

The website provides information about environmental issues and encourages users to participate through volunteering, donations, feedback, and social media engagement.

---

## 📌 Project Overview

EarthGuardians is designed as an awareness-based environmental website that demonstrates the use of fundamental **HTML, CSS, and JavaScript** concepts.

The website contains multiple pages and sections that allow users to:

- Learn about environmental preservation
- Understand the organization's mission
- Explore environmental initiatives
- Get involved through donations and volunteering
- Contact the website creators
- Submit feedback
- Connect through social media

---

## ✨ Features

### 🏠 Home Page
- Environmental-themed landing page
- Navigation bar
- EarthGuardians branding
- Hero section with a sustainability-focused message
- Introduction to the organization

### 🌱 About Us
Provides information about EarthGuardians and its mission to:

- Promote sustainable practices
- Raise environmental awareness
- Encourage community participation
- Protect the planet for future generations

### 🌳 What We Do

The website highlights three major environmental initiatives:

#### 1. Deforestation Prevention
Focuses on reducing deforestation, protecting habitats, preserving biodiversity, and addressing carbon emissions.

#### 2. Climate Action
Promotes efforts to reduce the effects of climate change and encourage sustainable practices.

#### 3. Wildlife Protection
Highlights the importance of protecting wildlife and maintaining healthy ecosystems.

### 🤝 Get Involved
Users can explore ways to contribute to environmental causes.

The page includes a **Donate Now** button that displays a thank-you message using JavaScript.

### 📩 Contact Us
Includes:

- Website creator information
- Email and phone details
- Contact form
- Send Message button

### 💬 Feedback
A dedicated feedback page allows users to submit:

- Name
- Email
- Message

It also provides **Send Message** and **Reset** buttons.

### 📱 Follow Us
The homepage includes social-media links allowing users to connect with the organization through external social platforms.

## 🚀 How to Run the Project

Since this is a static website, no special installation or server setup is required.

### 1. Download or Clone the Repository

```bash
git clone <repository-url>
```

### 2. Open the Project Folder

```bash
cd Mini-Project-main
```

### 3. Run the Website

Open:

```text
index.html
```

in any modern web browser.

You can also use **Visual Studio Code + Live Server** for easier development.
